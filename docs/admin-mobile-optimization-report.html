Before · 원인

고정 224px 사이드바 + 고정 좌측 여백

AdminSidebar.tsx가 반응형 숨김 없이 w-56 고정으로 렌더링되고, AdminLayout.tsx 본문도 ml-56 p-6을 유지해 390px 화면의 약 57%를 좌측 메뉴가 점유했습니다. 하위 페이지에서는 6열 고정 탭(grid-cols-6), 한 줄 액션 버튼 4개, 2열 고정 폼(grid-cols-2)이 모바일에서 찌그러질 위험이 있었습니다.

After · 해결

lg 기준 드로어 전환 + 2단계 하위 페이지 반응형화

AdminSidebarNav를 분리해 데스크톱(lg:block)은 기존 고정 사이드바를 유지하고, 1024px 미만에서는 헤더 좌측 햄버거 버튼 + shadcn Sheet(side="left") 드로어로 전환했습니다. 라우트 전환 시 자동 닫힘(pathname 연동)과 useSyncExternalStore 기반 안전한 하이드레이션을 적용했습니다.
