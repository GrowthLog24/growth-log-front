## 주요 결정 사항

### 1. 키워드 간접 링크 구조
QR을 직접 목적지 URL로 굽지 않고 `/apply/{keyword}`를 거치게 함.
→ 이미 인쇄된 홍보물을 그대로 두고 이동 주소만 바꿀 수 있고, 스캔 수 집계도 가능.

### 2. QR 기준 주소
관리자 화면은 `admin.*` 서브도메인에서도 열리기 때문에 `window.location.origin`을 쓰면
QR이 admin 도메인을 가리키게 됨. → `SITE_METADATA.url`(공개 사이트 주소)을 사용하되,
localhost에서는 만든 링크를 바로 눌러 확인할 수 있도록 현재 origin을 사용.

### 3. 스캔 수 기록 실패 처리
통계는 부가 기능이므로 실패해도 리디렉트를 막지 않음 (에러 로그만 남김).

## 발생 이슈

### 이슈 1: 로컬 dev 서버 500 (`@tailwindcss/typography` 해석 실패)
- 원인: `node_modules`에 `@tailwindcss/typography`, `gsap`, `jszip`이 설치되어 있지 않았고,
  `.next` 캐시도 오래된 상태 (이번 작업과 무관한 기존 환경 문제)
- 해결: `npm install` 후 `.next` 삭제 → 정상 동작. `package-lock.json` 변경 없음.

## 검증
