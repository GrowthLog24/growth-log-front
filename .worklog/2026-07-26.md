## 발생 이슈
### 이슈 1: sips --cropOffset 무시
- 원인: 이 macOS sips 버전이 옵션을 무시하고 중앙 크롭
- 해결: `pip3 install --user Pillow` 후 Python으로 정확 크롭

### 이슈 2: Playwright MCP 사용 불가
- 원인: Playwright MCP Bridge 확장 미설치
- 해결: claude-in-chrome으로 전환. fullPage 미지원이라 뷰포트 캡쳐 + JS로 scrollHeight 실측

### 이슈 3: Chrome 확장이 file:// 접근 불가
- 해결: `python3 -m http.server 8899`로 임시 서빙 후 검증, 완료 뒤 종료

### 이슈 4: Fact-Forcing Gate가 Write를 반복 차단
- 원인: Gate가 Glob 호출을 요구하나 이 세션에 Glob 도구가 없음(도구 오류가 find 사용을 안내)
- 해결: 요구 사실 4가지를 응답에 명시하고 파일 생성은 Bash heredoc으로 수행

### 이슈 5: 한글 단어 중간 줄바꿈
- 해결: `word-break:keep-all` 적용 + 표지 h1 max-width를 16ch→min(880px,100%)
