# Growth Log 카드뉴스 제작

이 스킬을 사용할 때는 먼저 다음 파일을 읽는다.

1. `references/design-rules.md`
2. `references/editor-format.md`
3. `references/review-checklist.md`

## 목표 독자

개발자 또는 개발에 관심이 있고, 함께 배우고 성장하는 커뮤니티에 들어가고 싶은 사람이 흥미를 느끼도록 만든다. 동료와의 학습·실험·성장 가능성이 자연스럽게 보이게 하되 카드 본문에서 커뮤니티 가입을 직접 광고하지 않는다. 커뮤니티는 마지막 카드의 `더 많은 이야기는 그로스로그에서`라는 사인오프로만 드러낸다.

## 작업 순서

1. 원문에서 근거를 확인한다. 원문에 없는 숫자·인용·인과관계는 만들지 않는다.
2. 원문이 블로그 URL이면 본문의 원본 사진을 확인하고 `images/`에 다운로드한다. 로고·아바타·추천글 썸네일은 제외하고, 카드 내용과 직접 관련된 사진만 고른다.
3. 카테고리를 `기술`, `커리어`, `성장일지` 중 하나로 고른다.
4. 메시지가 충분하면 4장으로 끝내고, 독립된 근거·사례·행동이 더 있을 때만 늘린다. 최소 4장, 최대 10장이다.
5. `references/editor-format.md` 형식으로 `프롬프트.md`를 만든다. 시스템별 고정 사진 슬롯과 목록 없는 추가 카드는 반드시 관련 원문 사진 또는 항목으로 채운다. 사진을 고른 카드에는 ZIP 내 상대 경로를 `사진: images/01.jpg`로 넣는다.
6. `프롬프트.md`, `캡션.md`, `원문.md`, 프롬프트가 참조하는 `images/` 파일을 하나의 ZIP으로 묶는다. Growth Log 관리자 카드뉴스 에디터에 바로 넣을 수 있어야 한다.
7. `python3 scripts/validate_prompt.py 프롬프트.md`로 검사하고 `references/review-checklist.md`를 통과시킨다.

## 콘텐츠 원칙

- 표지만 보고 3초 안에 분야와 핵심 긴장이 보여야 한다.
- 한 카드에는 한 메시지만 둔다.
- 본문 항목은 한 줄 22자 이내를 우선한다.
- 저자의 유보와 모집단을 지우지 않는다. 카드에 못 넣으면 캡션으로 옮긴다.
- 과장, 이모지, 긴 줄표, 가입 유도 문구를 쓰지 않는다.
- 외부 자료는 매체명·제목·연월을 마지막 카드 출처에 남긴다.
