# 발행 전 검수

- [ ] 원문의 근거 없이 만든 숫자·인용·인과관계가 없는가
- [ ] 개발자 또는 개발 관심자가 동료 학습과 성장 가능성에 흥미를 느낄 만한가
- [ ] 커뮤니티 가입을 본문에서 직접 광고하지 않았는가
- [ ] 카드가 4~10장이고 반복해서 장수를 채우지 않았는가
- [ ] 카드마다 메시지가 하나인가
- [ ] 제목 줄바꿈이 `\n` 문자가 아닌 실제 줄바꿈인가
- [ ] 블로그 URL 원문의 관련 사진을 ZIP에 넣고 `사진:` 경로로 연결했는가
- [ ] 시스템별 고정 사진 카드가 모두 채워졌는가 (`정기모임` 1~4번, `프로젝트` 1번, `성장일지` 3번, `그로스톡` 1·3번)
- [ ] `프로젝트` 2~4번은 사진이 있을 때만 넣었는가 (없는 카드에 억지로 채우지 않았는가)
- [ ] 5~10번 추가 카드가 사진 또는 항목 3개로 하단 영역을 채웠는가
- [ ] 사진형 카드의 제목과 받침이 안전 영역을 넘지 않는가
- [ ] 해외 수치의 국적과 모집단이 받침에 있는가
- [ ] 자체 표지는 `#75D565`, 외부 표지는 흰색, 본문 형광펜은 `#B3EEAA`인가
- [ ] 주황·그라데이션·취소선·명조·이모지·장식 도형이 없는가
- [ ] 마지막 카드에 항목 3개와 `출처:` 형식의 사인오프·정확한 출처가 있는가
- [ ] 에디터가 인식하지 않는 `사인오프:` 필드를 쓰지 않았는가
- [ ] 최종 이미지가 장당 2160×2700인가
- [ ] `카테고리:`·`대상:`에만 쓰고 라벨(`라벨:`)에 반영을 빠뜨리지 않았는가 (에디터는 두 필드를 읽지 않는다)
- [ ] 미리보기나 목업을 만들었다면 로고를 새로 그리지 않고 `assets/logo-on-light.png`·`logo-on-dark.png`를 그대로 썼는가
