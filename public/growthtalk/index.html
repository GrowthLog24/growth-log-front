v23 · v25가 나오면nodejs.org에서 24 LTS를 설치하거나, nvm을 쓴다면 nvm install 24 → nvm use 24. REA는 그 터미널의 기본 node로 실행되므로, setup 전과 에이전트 실행 전에 node -v 가 22 또는 24인지 다시 확인하세요. 25에서도 EBADENGINE 경고만 뜨고 돌아가긴 하지만 권장하지 않습니다.

  3. node는 22 또는 24가 기본이어야 합니다. 시스템 기본이 23 · 25면 rea 도 그 버전으로 뜹니다. setup 전, 에이전트 실행 전에 nvm use 24 등으로 맞춰 두세요.

② Lab 1 · 설치·연결15분

REA를 내 에이전트에 연결하기

REA는 MCP 서버, 에이전트 스킬, CLI(rea)가 같은 도구를 공유하는 묶음입니다. setup 한 번으로 MCP 등록과 스킬 설치가 같이 끝나고, 설정 파일을 바꾸기 전에 미리보기를 보여 주고 승인을 받습니다.

  1. 새 터미널에서 setup 실행

    에이전트 대화창 말고, 일반 터미널 창에서 실행하세요.

    처음엔 npm이 Ok to proceed? (y) 로 패키지 다운로드를 묻습니다. y. 이건 npm의 확인이고, REA의 설정 승인은 뒤에 따로 나옵니다.

  2. 에이전트 고르기

    Which agents should use REA? 목록에서 내 에이전트를 고릅니다. ↑↓ 이동 · Space 선택 · Enter 확정.

    중요Detected(감지됨)로 표시돼도 자동으로 체크되지 않습니다. 내 에이전트를 Space로 직접 체크하세요.

    선택 화면을 건너뛰고 싶다면 대신 이렇게 실행해도 됩니다.

③ Lab 2 · 증거 수집15분

디버그 Chrome을 띄우고 증거 모으기

REA는 원격 디버깅 포트(9222)로 열린 Chrome에 붙어 페이지를 지켜봅니다. 최신 Chrome은 기본 프로필에서 원격 디버깅을 막기 때문에 별도 프로필 폴더(--user-data-dir)가 꼭 필요합니다.

10분 규칙Lab 2를 시작하고 10분이 지나도 P1이 안 끝났다면 기다리지 말고 플랜 B 증거팩으로 바꿔 Lab 3로 넘어가세요.

  1. 디버그 Chrome 실행

    이 터미널은 켜 둔 채로 두고, 에이전트는 다른 터미널 탭에서 씁니다. 평소 쓰던 Chrome은 그대로 둬도 됩니다. 새 프로필 창이 따로 뜹니다.

    macOS

    Windows

    Chrome을 사용자 계정에만 설치했다면 경로가 $env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe 입니다.

    Linux

    Chromium이면 chromium 또는 chromium-browser. 키링 잠금으로 첫 화면에서 멈추면 --password-store=basic 을 추가하세요.

    이 창에서는개인 계정에 로그인하지 마세요. 관찰 결과는 에이전트의 모델 제공자에게 전달됩니다.

    원본과 같은 크기로 비교하고 싶다면 --window-size=1440,900 을 추가하세요. 이때 실제 페이지 영역은 1440×813입니다.

  2. 포트 확인

    디버그 Chrome에서 새 탭을 열고 아래 주소로 가 보세요. Browser, webSocketDebuggerUrl 이 들어 있는 JSON이 보이면 준비 완료. growthlog.org 탭은 열어 둡니다.

  3. P1 · 증거 수집

    새로고침 금지관찰 중에 그 탭을 새로고침하면 스크립트 수집 중엔 No script for id, 네트워크 관찰 중엔 target_changed 오류가 납니다.

    REA 결과는 1~4MB라 에이전트가 파일로 저장해 나눠 읽으면서 승인 창이 여러 번 뜰 수 있습니다. "이 세션 동안 허용"을 고르세요.

    강사 실측(홈, 8.8초): 접근성 트리 593노드, DOM 754노드, 스크립트 17개, 리소스 24개. DOM은 구조와 속성 이름만 저장하고 class·href 같은 값은 남기지 않습니다. 그래서 다음 단계가 필요합니다.

  4. P1+ · 공개 HTML로 보강

    리허설에서 REA 증거만으로는 히어로 영상, 블로그·아바타 이미지 URL(Firebase), 호버 클래스가 부족했고, 공개 HTML 한 번으로 채웠습니다. evidence/SUMMARY.md 에 관찰 / 추론 / 미확인이 나뉘어 있으면 Lab 2 완료.
